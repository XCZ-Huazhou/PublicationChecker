# PublicationChecker 优化排查清单

每次改完插件，按这份清单跑一遍，**全绿再交付**。下面所有数字都是本机实测值
（Chrome for Testing 156 + 独立临时 profile，全程不碰日常浏览器）。

## 怎么跑

前置：`D:\Softwares\DailyWork\BrowserPlugin\.tooling\chrome-win64\chrome.exe`
（必须是 CFT：品牌 Chrome ≥137 会静默忽略 `--load-extension`，测出来全是假绿）。

```
node tools/qc/qc-mv2-contract.js        # 秒级，不需要浏览器
node tools/qc/qc-page-classes.js        # 约 40s
node tools/qc/qc-overlay-anchor.js      # 约 60s
node tools/qc/qc-popup-list-restore.js  # 约 60s
node tools/qc/qc-hover-close.js         # 约 40s
node tools/qc/qc-results-paging.js      # 约 60s
node tools/qc/qc-open-timing.js         # 约 60s；加 PC_IDLE_MS=70000 测冷启动
```

默认加载本仓库目录；`PC_EXT=<目录>` 可指向别的构建（例如对比 `PublicationChecker-chrome`）。
每个脚本自己建并自己删 `.qc-*-profile` / `.pc-*-profile`，不会留临时目录。

> 三个入口现在共用一条原则：**「其他匹配」列表常驻，点候选只换上面的主卡片**，谁都不许把列表整块抹掉。
> 差别只在输入框：弹窗（popup.js）点候选会回填刊名方便接着改，所以额外给一条「← 回到第 1 条（原词）」
> 把主卡片和搜索词一起复原；结果页（results.js）和浮层（content.js）不回填，因为它们的框里就是用户自己打的词。

> 自动关闭**只有一个开关**：`content.js` 里的 `HIDE_DELAY`（当前 300ms）。
> QC 输出里的 150ms / 700ms 是采样时刻（用来证明关闭落在这个数附近），不是可选项。

## 已确认的浏览器硬限制（别再当 bug 查）

- `chrome://` 页面（含**新标签页**，它长得跟 Google 首页一模一样）、扩展商店、内置 PDF 查看器：
  内容脚本注不进去，`scripting.executeScript` 直接被拒。这类页面右键只能落回结果页。
- 输入框（`<input>`/`<textarea>`）里的选区**不属于文档选区**，`window.getSelection()` 拿到 0×0 矩形。
  所以浮层锚点必须退到聚焦控件自身的矩形（`content.js` 的 `focusedFieldBox()`），否则会掉到居中兜底位置。
- 点工具栏图标后那一下"停顿"来自 Chrome 创建弹窗窗口本身：popup 页面侧只有 50–130ms，
  而且 popup **完全不跟 service worker 通信**，所以加 SW 保活心跳不会有任何改善（已实测排除）。
- 加载 29.8MB 的源码目录和 2.3MB 的精简构建目录，弹窗耗时**没有可测差别**，不用为此换加载路径。

## 出包核验（每次都要做）

1. `node build-chrome.js && node build-firefox.js`
2. 解包 grep 关键改动确认真的上车了（`.xpi` 要先改名成 `.zip` 才解得开）：
   `focusedFieldBox`、`showDetail`、`file: CS_FILES`、`if (root.PublicationChecker) return`
3. 包里不得有 `.git` / `raw` / `tools` / `docs` / `*.bak*` / `manifest-mv2.json` / `background-mv2.js`（Chrome 包）
4. 两个 manifest 版本号一致；Firefox 包 `browser_specific_settings.gecko.id` 固定为
   `publication-checker@xcz-huazhou`
5. Zen 若在运行会锁住 profile 里的 xpi（`部署失败：Zen 正在运行…`）——**不要强杀 Zen**，
   等它关掉后重跑 `build-firefox.js`

## 双入口与兄弟扩展

- 浮层（content.js）和弹窗（popup.js）是两套渲染代码，任何行为改动都要**两边对齐**再各自实测。
- 期刊名相关的检索能力改动，同步检查 BrowserCode / AssetSieve 是否也该跟上。
